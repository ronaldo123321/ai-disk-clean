# 清理大师交互提案

打开 `index.html` 即可体验；同目录的 `flow.svg` 是独立交互流程图。不依赖网络或第三方库。

这是设计评审原型，没有接入 Swift 应用，不读取、移动或删除真实文件。所有数字、路径、权限、扫描、清理和恢复都是模拟数据。刷新或「重新体验」会重置状态；长期保留仅在本次页面体验中跨扫描生效。修改扫描路径演示方案失效与重新扫描，示例条目不随真实目录变化。

## 建议体验顺序

1. 项目清理：切换父子项选择，搜索和排序，查看保护原因，设置长期保留。
2. 扫描范围：添加模拟目录、启动或取消扫描，查看权限不足的结果说明。
3. 确认单：查看立即释放与恢复区的分项数字，勾选知情确认，模拟执行。
4. 默认分支：`.venv` 执行前发生变化，跳过它，继续处理已验证条目。
5. 历史与恢复：演练还原、同名冲突保留双方、另存恢复及永久清空二次确认。
6. 顶部切换流程图；空间浏览是 P2 独立只读交互示例。
