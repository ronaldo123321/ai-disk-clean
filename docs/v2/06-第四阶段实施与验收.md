# V2 0.6.0：第四轮实施与验收

2026-09-18，分支 `codex/cleaner-v2`。本记录更新 05 中对应的未完成项；开发版仍不等于公开发行版。

## 本轮新增

- **四类适配补齐**（对应用户路线图第 1 项的 uv / Homebrew / Playwright / Puppeteer 四类）：
  - `UVAdapter`：`uv --version`、`uv cache dir` 两个只读官方命令发现；已验证并登记 uv 0.11.19（conda 安装）与 0.12.11（~/.local/bin 独立安装，适配器优先取稳定位置而非继承 PATH）。绿色整类命令 `uv cache prune`——uv 只提供整类清理能力，无逐文件枚举接口，按 PRD「命令只能整类执行就展示整类动作」呈现；uv 自身的 in-use 检查与缓存锁守卫（`~/.cache/uv/.lock`）双重保护。
  - `HomebrewAdapter`：稳定路径发现（/opt/homebrew → /usr/local → PATH）、`--version`/`--repository` 只读查询；登记 Homebrew 7.0.1。绿色整类命令 `brew cleanup -s`；占用守卫为 `--repository` 核实的锁目录（目录型守卫走 `lsof +D` 递归检测）。
  - `PlaywrightAdapter`：不需要工具进程。用 Playwright 官方 `INSTALLATION_COMPLETE` 安装完成标记逐目录验证，目录名严格匹配 `chromium-1181` 等官方命名。本机实测 16 个带标记安装全部纳入，无标记的中断目录（`b`）与内部目录（`daemon`）正确排除。黄色逐项目录候选，移入恢复中心可还原。
  - `PuppeteerAdapter`：按官方文档缓存布局 `<browser>/<platform>-<version>` 枚举，浏览器名限官方四款，版本目录严格格式校验。黄色逐项目录候选。
  - 适配器产出统一带 `adapterEvidence`（版本、可执行路径、机制、数量）；任何验证失败保持红色只读。
- **引擎：目录型候选全链路**。Scanner 清单分支接受目录（du 口径计大小）；Planner 为目录候选生成逐项锁守卫；Executor 身份校验接受目录、拒绝符号链接。
- **引擎：整类命令授权通道**。Executor 边界仅接受 `V2Policy.commandAdapterIDs` 中规则的逐字命令；授权清单 `V2Policy.authorizedCommands` 由适配器按当前机器重新推导（不接受规则文件自声明命令，伪造规则携带任意命令在两道校验下都无法执行）。命令项不携带文件身份约束（锚点目录随工具活动变化），15 分钟方案时效照常生效。
- **引擎：目录型隔离批次内容清单**（收紧 05 记录的已知边界）。admit 时递归记录副本清单（相对路径、device、inode、大小、类型，lstat 语义）；restore 与 purge 前逐项核对，任何缺失、新增、替换（含嵌套子目录变化，顶层身份快照无法发现）都保守拒绝并保留映射供检查。旧格式清单（无 inventory）回退为顶层身份校验。
- **策略**：`fileAdapterIDs` 加入两个浏览器适配器；遗留 `puppeteer-cache` 旧 id 被 discover 取代（本机存量 rules.json 不再出现重复展示）。

## 验证结果

- `swift test`：152 项，150 通过、2 跳过（真机门控用例）、0 失败。新增 27 项：四适配器版本门禁、越界/保护/异常输出保持只读、目录清单语义、命令授权与伪造命令拒绝。
- `DCLEAN_SMOKE=1` 真机只读验证：完整 home 扫描 27.4s 无崩溃；五个适配器全部产出有效规则且带证据。
- **真实清理闭环（临时夹具）**：扫描 → 预览（逐项选择）→ 隔离 → 恢复（逐字节一致）→ 再次隔离 → 单项确认永久清除，全程通过并落审计（apply.intent / restore.done / purge.done）。
- 闭环覆盖：文件被占用（测试进程真实持有句柄，lsof 判定 blocked，执行跳过其余条目继续）、根目录权限不足（扫描报告 unavailable，不产生清理项）、隔离目录被部分删除（restore 与 purge 双双保守拒绝，清单保留）、未注册命令（跳过并如实记账，绝不执行）、方案超过 15 分钟（拒绝执行）。
- 中断续作、清单损坏保护由第三轮既有测试继续覆盖；磁盘满、物理断电与外接盘场景仍不在自动化范围。
