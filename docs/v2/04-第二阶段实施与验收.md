# V2 0.4.0 开发版：第二阶段实施与验收

2026-09-18，分支 `codex/cleaner-v2`。本记录补充并更新 03 文档；未列为完成的发行条件仍然待验收。

## 本轮完成

- 新增下载目录顶层、60 天前 `.dmg` 文件的确认后整理；默认不选，保留内容价值不确定的提示，只移动到恢复中心。磁盘映像不等于垃圾，不自动删除。
- 详情支持逐文件排除/纳入；预览范围仅包含所选文件。新扫描会清空选择。
- 自定义保护文件/目录存储于 `~/.dclean-protected.json`，GUI/CLI 共用；核心保护不能移除，配置损坏时阻止执行。保护对象的父目录整体删除同样拒绝。
- 恢复中心支持单项恢复、选择本机 Home 内的其他目标目录、再保留 30 天；目标冲突不覆盖，跨卷操作拒绝。
- 扫描支持取消，不完整结果不能生成计划；执行支持停止后续项，已完成结果保留。
- 同一 Home 共用文件锁，覆盖 GUI、CLI、恢复、清除和保护设置变更；进程退出后锁自动释放。
- 计划最多有效 15 分钟；绑定规则摘要，应用执行器重新核验当前策略、动作、范围、类型、年龄与占用守卫，拒绝改写计划绕过适配器。
- 进程双管道非阻塞读取，10 秒默认超时、每管道 1 MiB 上限；超时/输出超限按未知处理。
- 修复 `*` 后字符被吞掉的 glob 错误；拒绝计划中的重复及父子重叠范围。
- 文件移动通过逐层不跟随链接的目录描述符及禁止覆盖 rename 执行；不使用跨卷复制后删除的回退。
- 恢复清单原子替换并同步写入，审计追加同步写入；还原和清除前必须成功记录意图。
- 恢复中心发现未登记文件时保留，不随批次递归删除；清除过程中先处理登记内容，最后清理清单。
- 结果增加可用空间观测变化，明确区别于直接处理量。

## 验证

- `swift test`：102 项，101 通过、1 跳过、0 失败。跳过的是默认禁用的真实 Home 测试。
- 新增 18 项测试：glob 后缀、互斥、过期计划、取消、保护设置及损坏、规则更新、单项冲突另存、保留期、未知恢复文件、父目录链接、超时、双管道与输出上限、当前策略完整移入/恢复链路、取消扫描及重叠范围。
- 当前策略完整链路使用真实临时文件，进程占用结果通过测试替身注入；不能等同于全部真实应用兼容性认证。
- 原生 UI 检查：新保护入口可见；真实只读扫描可取消，结果标记不完整。没有通过 UI 移动、删除或永久清除真实用户文件。
- Release 打包及本地 ad-hoc 签名验证通过，不等同于 Developer ID 签名或 Apple 公证。

## 仍未完成，不能据此全公司/公开发行

- pip、uv、Homebrew、浏览器及模型缓存仍为只读；工具版本、依赖、离线成本的适配矩阵未验证。
- 完整的权限覆盖/深层目录读取失败报告、扫描大小去重、应用级分布与预估释放量仍待完善。根目录权限错误已有显示，不能宣称全盘完整扫描。
- 原子条件移动的最后瞬间对象替换竞态、旧目录型恢复批次的所有并发场景、清除部分失败的自动续作及恢复日志修复向导仍待完善。当前映射会保留，可能需要人工检查；不宣称所有崩溃都能自动恢复。
- 持久化写入不等于经过断电实验；审计尾部损坏检查及所有后置审计失败的中止语义仍待完善。
- 完整 UI 的恢复/清除端到端测试、键盘辅助功能矩阵、多系统与文件系统矩阵、小范围用户试点尚未完成。
- 自动扫描提醒、报告导出、企业策略收紧、正式发行签名与公证尚未完成。企业控制台和云端 AI 不属于已批准首版范围。

## 体验方式

打开最新 `build/DiskCleanerV2-*.app`，窗口标题含 `V2 开发版 · 0.4.0`。GUI 数据继续位于 `~/.dclean-v2`，CLI 继续位于 `~/.dclean`；保护位置和操作锁共用。不要从仍显示“隔离 7 天后删除”的旧面板判断新版行为。
