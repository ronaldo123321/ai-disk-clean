# V2 0.8.0：第六轮实施与验收

2026-09-18，分支 `codex/cleaner-v2`。本轮处理遗留问题清单中的 C 项（V1/V2 共存冲突）并启动 A 项（产品内缺口：A2 已完成、A1 完成首轮界面验收）；开发版仍不等于公开发行版。

## C：V1/V2 共存冲突（已消除）

- 问题：V1（master 构建）与 V2 共用 `~/.dclean`；V1 扫描自动清除 7 天以上隔离批次，会提前物理删除 V2 恢复中心批次（30 天保留、到期只提醒）。
- 修复：`V2Paths` 单一来源贯通 GUI / CLI / OperationLease / ProtectedLocations，全部收口到 `~/.dclean-v2`；操作锁迁入数据目录并在写入前自动建目录；保护位置文件更名 `protected.json`。
- 迁移：已核实 `~/.dclean` 中无任何隔离批次，无需迁移；V1 仍可独立运行不受影响。
- 回归：`V2DataIsolationTests` 钉死路径布局——V2 组件不得触碰任何 `~/.dclean*` 遗留路径。

## A2：到期提醒可见性（已完成）

- 概览页新增橙色横幅：「N 个恢复中心批次已过提醒日期」+ 说明（到期不自动删除）+ 「查看恢复中心」跳转。
- 截屏验收：真实过期批次（临时构造，验收后已清理）触发横幅正确显示。

## A1：界面验收（首轮完成，发现并修复一个真 bug）

验收方法：`screencapture` 按窗口 id 截取真实渲染内容（发现截屏与 AX 均受系统权限与枚举限制后，为应用新增两个环境变量门控的验收钩子，默认关闭）：
- `DCLEAN_UI_TOUR=<页名>`：直达指定页；
- `DCLEAN_AUTO_SCAN=1`：启动后自动开始一次只读扫描。

验收中发现并修复：

- **部分阻塞粒度 bug**：计划预览把「任意单个候选被占用」当「整条规则被阻」，导致 Playwright 整条规则从「需要确认」消失（17 项中 15 项可清理却全部陪葬；本机实测 2 个版本目录被 NotificationCenter 持有）。修复：`blockedNotes`（全部被阻，禁用勾选）与 `partialBlockedNotes`（部分被阻，行内橙色标注「2/17 项被占用将跳过」，其余照常勾选）分离；占用者文案去重。
- 顺带确认：目录型 `lsof +D` 占用守卫在真实环境命中了真实占用者（NotificationCenter 持有 chromium 缓存内文件），守卫机制按设计工作。
