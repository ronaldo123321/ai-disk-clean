# AI 清理大师 V2 · 产品需求与交互

2026-09-18｜已获用户确认的方案 v0.1｜分阶段开发中；实际完成情况见各阶段验收记录。

## 1. 产品目标与范围

面向 macOS 办公与开发用户，让用户知道空间在哪里、处理会影响什么、哪些操作能恢复。共享同一安全引擎，公司策略只能收紧安全边界。

首版包括：只读空间概览、清理建议、应用详情、确定的执行计划、结果、恢复中心、保护位置与活动记录。开发工具按设备实际发现，普通用户不必选择职业模式。支持版本在适配验证后逐个登记；未知版本仅展示。

首版不含：全盘一键删除、自动删工作资料、应用卸载/重置、杀毒、内存加速、云端文件清理、跨卷自动迁移、远程 Docker 操作、企业控制台。AI 可解释和排列合法候选，首个安全版本不依赖 AI 服务。原型的解释为预写内容，不接大模型。

## 2. 用户任务

- 办公：空间不足时找到可处理内容，确认不会删工作记录；不需要理解 CLI 或路径。
- 开发：看清浏览器、构建缓存、模型的版本和依赖，保护在用项目与离线资源。
- IT：理解规则版本、失败原因、受保护范围，为小范围试点验证行为；首版使用本地报告，不上传员工文件明细。

成功不以“扫出多少垃圾”为指标。重点：误分类情况、用户对不可恢复操作的理解、任务完成、恢复成功、失败是否准确报告。

## 3. 策略契约

四种处理资格：推荐清理、需要确认、暂不可处理、受保护。另设独立的影响、动作、恢复能力和证据字段。

- 推荐：适配器验证、低影响、边界确定、状态空闲、无策略冲突。推荐不等于后台自动删除。
- 需要确认：有明确操作能力，但重建成本或内容价值需要用户决定，默认不选。
- 暂不可处理：占用、未知、权限缺失、版本不支持、计划过期或状态变化；不可勾选，不提供强制按钮。
- 受保护：会话、记忆、凭据、数据库、源码、用户指定位置、企业留存位置；不产生清理计划。

设计默认：自动删除关闭；自动扫描可由用户启用；首次扫描完成后零项选中，用户可点“选择推荐项”。恢复中心默认保留 30 天，到期只提醒。试点不开放自动到期永久删除。保护优先于建议、用户选择和企业允许策略。

文件时间只作证据之一。重复内容不等于可删除；重复文件功能放在后续版本，必须保留原件位置、检查依赖，不能通用替换硬链接。

## 4. 信息架构与布局

菜单栏只展示磁盘状态、最后扫描时间和打开主窗口入口。主窗口建议宽 1120、高 760，可缩至 900；浏览器原型另做窄屏退化。左侧导航：概览、清理建议、恢复中心、活动记录、设置。首版空间分布并入概览，不另建复杂分析器。

使用浅暖背景、深色正文、低饱和绿色操作色。危险永久删除用红色；状态同时有文字，不只靠颜色。数字等宽，文件名可完整展开，长路径可复制但不是主信息。主操作固定在建议页底部，不遮挡最后一行。

## 5. 页面与状态

### 首次使用与扫描

打开后解释“仅分析授权位置，扫描不修改文件”。点开始后显示阶段、范围、取消按钮；取消保留已读结果并明确不完整。权限按需申请，拒绝可继续部分扫描。未知、权限不足、未安装、空目录不能混同。

结果按本次扫描快照计算；零结果显示“当前没有符合策略的清理建议”，不制造紧迫感。扫描失败保留旧结果并标记过期，不允许直接执行旧计划。扫描超时可重试特定范围。

### 概览

显示磁盘容量、实际可用空间、最近扫描、覆盖范围、未授权范围。展示“预计可直接释放”“可移入恢复中心”“暂不可处理”三个不同口径，不相加为虚假总回收。

空间条表示磁盘占用分类，不等同于可清理候选；系统管理与未识别空间标清。主按钮“查看清理建议”。

### 清理建议

按处理资格切换，列表包含应用/对象、大小、简短影响、动作与恢复方式。默认不选；“选择推荐项”仅在当前扫描的合格项中选择。刷新或规则变化不继承已选择的新增对象。

行详情侧栏显示：是什么、证据、处理影响、能否恢复、执行范围、高级路径。动作“本次跳过”和“保护此位置”独立；永久保护要明确保护对象，不把“保护一个文件”升级为整个 home。仅模型/版本的具体可清理对象进入清单，不操作根目录。

命令若只能整类执行，就展示整类动作，不给出无法兑现的逐文件勾选。候选集变化或工具无法限定范围时要求重新预览，不悄悄扩大执行范围。

### 计划预览

以显式动作分组：直接清理（不可还原）、移入恢复中心（同卷移动，暂不释放空间）。分别列出大小、数量、影响、过期时间、无法估计项。高影响或永久操作的文字确认只用于说明不可逆后果，不做每次输入口令式仪式。

不可逆选项存在时，用户明确勾选“我知道直接清理的内容不能从本工具还原”；纯隔离计划不强制勾选这条。主要按钮“执行这份方案”，次按钮“返回调整”，Escape 取消。

### 执行及结果

计划预检 → 逐项复核 → 执行 → 核验 → 记录。普通项目占用/变化：跳过并继续其他项目；安全红线/日志失效：中止后续。取消仅停止后续项，当前不可中断动作等待安全结束；不承诺撤销已完成永久删除。

结果分别报告已完成、跳过、失败；只在全成功时称“处理完成”，否则“部分完成”或“已停止”。显示直接处理量、移入量、可用空间观测变化；APFS 快照等可能导致两者不一致。不用动画累加虚假释放量。

### 恢复中心

> **0.9.1 设计修订（用户决策）**：清理项的存储由自建隔离区改为**系统废纸篓**。还原仍经本工具（保留身份校验、目录内容清单与崩溃安全日志）；「清倒废纸篓」即永久删除，由用户自行控制。原「30 天保留期、到期提醒、本工具内永久清除」随此修订取消。首次移入时 macOS 可能弹一次废纸篓访问授权。

每项显示来源应用、对象名、原位置、移入日期、状态与占用。支持逐项还原、还原至其他位置。

还原先核验清单和路径，应用运行中暂停；原位置已存在时默认不覆盖，给出“还原至其他位置”或“暂不还原”。不提供整目录合并替换的便捷按钮。重启后可识别未完成移动并恢复日志。

永久删除单独预览、说明不可还原、再次核验；失败仍保留记录与恢复信息。到期不会自动删。隔离/还原不计入磁盘释放。跨卷首版禁止移入，明确说明原因，不回退为删除。

### 设置与活动

管理受保护位置、扫描提醒、本地隐私。核心保护不可关闭。首次添加路径需选择并显示实际范围。事件包含对象、动作、时间、规则版本、结果与原因；导出默认脱敏，具体路径仅用户本地查看。

## 6. 引擎约束与数据字段

Candidate：id、adapter/version、resource identity、bounded scope、eligibility、evidence、impact、action、recoverability、allocated size/estimate status、guard status、policy version。

Plan：不可变 plan id、候选对象身份及快照、规则版本、用户选择、目标卷/工具 context、建立时间与有效性条件。适配器变化、目标身份变化、扫描范围变化均使相关项失效。CLI 与 GUI 使用同一验证器。

最低约束：禁止任意 shell 配置；路径与对象双重围栏；链接安全操作；单执行任务互斥；计划重试不重复处理成功项；命令固定参数/目标校验；操作前持久化 journal；权限最小化；日志损坏不继续破坏性操作；恢复目标也复核围栏与链接；大小去重、防父子范围重叠。详细实现方案在设计通过后单独制定。

AI 只接收允许的候选摘要并返回候选 ID 与解释，不获得任意执行能力。文件名/文档中的内容属于不可信数据，不作为指令。默认本地，不上传内容；未来云端解释另做传输预览和授权。

## 7. 验收矩阵

| 编号 | 场景 | 验收结果 |

## 8. 交互原型的可验证范围

`prototype.html` 为零依赖本地 HTML，所有数据均为虚构。无文件系统读写、无系统权限申请、无清理引擎、无真实磁盘探测、无网络或 AI 请求。演示修改仅存在内存中，刷新或“重置演示”恢复。

覆盖：扫描与取消、部分权限提示、分组筛选、详情、选择推荐、保护、计划预览、执行、停止、占用变化跳过、模拟失败、恢复冲突另存、延长保留、永久删除确认、记录。设置中的开关仅改变本次演示，不代表真实系统设置。

建议演练：①扫描→推荐项→预览→执行；②选择安装包→移入→恢复；③演示情景设为“执行时占用”后重复流程；④设为“处理失败”；⑤在恢复中心尝试恢复同名冲突项；⑥单独确认永久删除。

## 9. 交付与试点顺序

先评审规则审计、PRD、原型。通过后实施 P0 引擎修复，再做 GUI。试点 5–8 人覆盖办公、开发、设计与 IT，先仅扫描/预览；通过测试目录破坏性验收后，由参与者主动选择少量已验证对象试用。

设计验证目标：每位参与者都能正确指出不可还原项及隔离不释放空间；核心流程完成率目标 ≥ 85%；安全用例全部通过后才开放试点执行。人数少，比例不作为统计证明。暂未做用户测试，不宣称上述目标已达到。

问题记录按：任务、停顿位置、误解、取消原因、是否误分类、期望动作、严重程度。优先解决误删风险和理解错误；不以新增清理种类替代安全验收。
