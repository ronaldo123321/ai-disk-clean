# 勾选状态与失效原因修复（2026-10-14）

## 改动

- 扫描范围按规范化路径集合比较，忽略重复项、顺序、末尾斜线；默认 Home 与显式 Home 等价。真正相同的范围保存不清空勾选、不使方案失效。
- 新增嵌套扫描目录仍使方案失效，因为以子目录为起点可能扩大扫描深度；不能当成无变化。
- 用明确原因替代“方案已失效”：范围/保留设置更改、扫描取消、扫描失败、清理后状态变化、恢复后状态变化。
- 提示旁提供“重新扫描以启用勾选”，成功扫描自动清除失效原因。
- 不可选条目直接显示下一步：需重扫、长期保留需到扫描范围移除、无法验证/受保护需查看详情、仅展示不提供清理；勾选框补充帮助文字。
- 失效状态下不再显示“已验证项可单独处理”；顶部改为“上次成功扫描”，并在结果失效时标记“结果待更新”。
