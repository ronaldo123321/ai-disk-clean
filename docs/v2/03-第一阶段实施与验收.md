# V2 第一阶段实施与验收

日期：2026-09-18。分支：`codex/cleaner-v2`。这是本机开发版，尚未达到全公司或公网发行标准。

## 已实施

- 原菜单栏面板升级为独立主窗口：概览、清理建议、恢复中心、活动记录、设置说明。菜单栏仍提供入口。
- 首次打开不自动扫描，不预选清理项；执行前生成确认计划。
- V2 运行时策略保留原始规则文件。会话、记忆、插件及未验证适配器只读；仅开放超过 30 天的 `.ips` 诊断报告进入恢复中心。
- 占用检查分为明确空闲、占用、无法确认；检查失败按不可处理对待。执行时重新检查对象身份、路径及占用状态；缺少快照的旧计划跳过。
- 命令执行默认拒绝，只有构造执行器时显式允许的命令可运行；命令返回成功不再记作确定释放空间。
- 扫描不再触发隔离区清除。恢复中心 30 天后仅提醒；永久清除需要显式操作，并绑定界面确认过的批次集合。
- 移动前写入恢复映射，清单使用原子写；拒绝跨卷移动、恶意批次路径和部分符号链接跳转；还原不覆盖同名文件。
- UI 防止扫描、生成计划、执行、还原及清除互相重入；还原和清除失败显式展示。
- 独立 GUI 数据目录 `~/.dclean-v2`，不迁移旧恢复批次。CLI 仍使用 `~/.dclean`，不要把新版 CLI 当作独立沙盒。
- 独立打包脚本 `Scripts/make-v2-app.sh`，带时间戳输出，不覆盖原 `build/DiskCleaner.app`。资源随包携带，本地 ad-hoc 签名验证通过；未做开发者公证或公开发行签名。

## 验证证据

- `swift test`：84 项，83 通过、1 跳过、0 失败。跳过的是默认不执行的真实 Home 测试。
- 新增 10 项安全回归覆盖：中断恢复映射、清单写失败、批次目录穿越、恢复父目录链接替换、同路径文件替换、执行时占用复核、进程检查异常、旧规则只读策略、恶意清单越界、确认批次范围。
- Debug / Release 编译通过，`git diff --check` 通过。
- 原生窗口启动、概览和恢复中心空态、设置说明经界面检查；真实只读扫描完成，显示磁盘空间与扫描范围，扫描后清理建议默认未选择、处理按钮禁用。未对真实工作文件执行移动、删除、截断或清除。

## 尚未完成的 V2 范围
