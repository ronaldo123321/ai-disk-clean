## 本轮发现并修复的问题

1. 受保护/完全无证据的范围被描述成“部分候选证据不足，请重新扫描”，容易误导用户重复扫描。现在区分受保护数据与尚无已验证清理依据。
2. GUI 与 CLI 的分类逻辑分散。增加共享 `presentationCategory`，保护优先，配置错误、不可读取或占用状态不得显示为可操作推荐；新增测试覆盖四分类与状态优先级。
3. 可选真机适配器测试假设 Puppeteer 缓存始终存在，且读取旧 V1 规则目录。本机无该缓存导致两条断言失败。测试改为读取 V2 规则，并验证环境对应的安全契约：未验证时无证据、无可执行清单；已验证命令必须有匹配的命令证据；文件适配器必须可逆且有候选清单。确定性的五适配器正向/负向夹具仍保留，不用环境假设替代这些测试。
