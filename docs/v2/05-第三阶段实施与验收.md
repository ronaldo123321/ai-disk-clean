# V2 0.5.0：第三轮实施与验收

2026-09-18，分支 `codex/cleaner-v2`。本记录更新 03/04 中对应的未完成项；开发版仍不等于公开发行版。

## 本轮新增

- pip 适配：通过 `--version`、`cache dir`、`cache list --format=abspath` 三个只读命令发现当前配置和明确文件集合。只登记本机核验过的 pip 21.2.4 / 24.3.1；其他版本和异常输出保持只读。只纳入工具列出的、超过 30 天的常规 wheel 文件，不猜内部目录结构，不调用 remove/purge，不操作 HTTP 缓存或已安装包。
- 用户可以逐项选择这些文件，确认后移入恢复中心。说明后续安装可能重新下载或编译，离线资源需要保留。文件集合、版本或工具路径变化会使原计划失效。
- 恢复清单新增逐项状态、对象身份及还原目标；移动、还原、清除均先持久化状态。重试会核对已完成动作，避免重复处理。原位置仍有未移动文件、已还原但末尾记录未写、已清除但末尾记录未写分别处理；无法核实的内容保留并显示异常提示。
- 恢复和清除时复核隔离对象身份与占用情况。被替换或无法确认空闲的对象不处理；终态与实际副本冲突时保留映射。
- 删除使用逐层不跟随目录链接的目录描述符操作，递归时拒绝跨卷；清理批次目录只允许删除空目录。清单重复路径、指向自身或异常还原目标被拒绝。
- 审计文件损坏或尾部不完整时阻止后续数据操作；后置审计失败在结果中标记停止，保留已完成结果。
- 恢复中心支持单项永久清除预览。只有用户单独确认的文件进入操作；允许用户主动在提醒日期前清除，默认到期流程仍不会自动删除。未选中的同批文件保持可恢复。
- 修复真实原生验收发现的首次打开详情为空，以及首次单文件勾选可能连带选择同类文件的问题。详情改为以具体条目驱动，首次单选会明确排除同类其他文件。
- 活动记录支持脱敏导出，只保留时间、固定动作类别、字节数，不包含文件名、路径或具体描述。

## pip 依据

- [pip cache 官方接口](https://pip.pypa.io/en/stable/cli/pip_cache/)：读取缓存目录与绝对文件列表。
- [pip 缓存说明](https://pip.pypa.io/en/stable/topics/caching/)：内部目录结构可能变化，缓存减少重新下载与构建。因此仅依赖公开枚举，保留重建成本提示。
